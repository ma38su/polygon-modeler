# ADR 0026: 数値変形プレビューとShift微調整

## Status

Accepted

## Decision

- Inspectorの移動・回転・スケール入力は、ドキュメントを変更しない一時メッシュとして表示する。
- `適用`時だけ既存の変形コマンドを実行し、プレビューを破棄する。
- Shift押下中はギズモへ細かなスナップ刻みを設定し、離した時に通常設定へ戻す。
- 移動は0.05、Grid併用時はGrid幅の1/10、回転は1度、スケールは0.01とする。

## Consequences

- 数値の試行錯誤でUndo履歴が増えない。
- 移動・回転・スケールの微調整が同じShift操作で行える。
