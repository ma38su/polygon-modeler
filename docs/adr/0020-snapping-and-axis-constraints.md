# ADR 0020: スナップと軸制限

## 決定

Transform設定としてグリッドスナップ、頂点スナップ、軸制限をViewportへ渡す。グリッドスナップは`TransformControls`の移動スナップを利用し、既定間隔を0.5とする。頂点スナップは要素移動中の選択Pivotを、未選択頂点のワールド座標へ吸着させる。軸制限は`all / x / y / z`の単一状態とし、ギズモの表示軸と移動・吸着対象軸を一致させる。

## 理由

スナップ計算はViewport座標系の責務であり、Editor Coreには確定後のローカル頂点座標だけを渡すことで描画依存を防げる。軸制限をUI、ショートカット、TransformControlsで共有すると、見えている操作軸と実際の結果が食い違わない。

## 帰結

Grid / Vertexは独立して有効化でき、X / Y / Zキーでも軸を切り替えられる。頂点候補の選択処理は純粋関数として分離し、将来のピクセル距離基準やEdge / Faceスナップへ置換可能にする。
