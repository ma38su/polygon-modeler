# ADR 0011: GLB / STL変換と単位

## 状態

採用

## 決定

内部モデルとGLBの単位はメートルとする。STLは単位情報を持たないため、3Dプリント用途の交換単位をミリメートルとし、出力時に1000倍、読込時に0.001倍する。

GLB / STL変換はThree.js公式のLoader / Exporterを使うが、依存は`editor/formats/exchangeFormats`境界へ限定する。読込GeometryはワールドTransformを頂点へ適用し、重複座標を統合した三角形Half-edgeメッシュへ変換する。読込結果の追加は単一のCompositeCommandにしてUndo可能にする。

既定では表示中のオブジェクトだけを出力し、UI設定で非表示を含められる。空シーン、表示対象なし、面のないメッシュはエクスポート前に理解可能なメッセージで拒否する。

## 理由

内部モデルをThree.js形式へ固定せず、保存形式と交換形式を分離するため。STLの慣例的なミリメートル運用を明示することで、スライサー上の寸法差を防ぐ。
