# ADR 0013: 要素選択モードと可視化

## 状態

ADR 0017により選択方式を改訂

## 決定

Objectはメッシュオブジェクト全体を選択・Transformするモードとする。Vertex / Edge / Faceは同じメッシュ内部の編集要素を選択するモードとし、選択対象の種類は排他的に切り替える。同一種類ではShift+クリックによる追加・解除と全選択に対応する。

Vertexモードでは全頂点、Edgeモードでは全辺、Faceモードでは全辺と選択面を描画用オーバーレイとして表示する。選択要素には共通のアクセント色を使う。オーバーレイはRenderGeometryAdapterが所有し、Editor Coreのメッシュへ描画状態を持ち込まない。

要素モードではオブジェクト全体用のTransformControlsを切り離す。要素TransformはInspectorのCommand化された操作を使う。

## 理由

Vertex / Edge / Faceを同時に混在させると、削除、結合、押し出し、Transformの対象規則が曖昧になる。種類は排他的、同種要素は複数選択可能とすることで、操作の意味と視認性を両立する。
