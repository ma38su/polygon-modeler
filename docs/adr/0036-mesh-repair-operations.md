# ADR 0036: メッシュ修復をUndo可能なObject操作にする

## 決定

- Merge by Distanceは指定距離をセル幅とする空間ハッシュで近傍27セルだけを検索する。
- 溶接後に連続重複Vertex、3頂点未満のFace、重複Face、未使用Vertexを除去してHalf-edgeメッシュを再構築する。
- 法線再計算は共有Edgeを介してFace windingを伝播し、閉じた連結成分は符号付き体積で外向きにする。
- 修復前後を`EditMeshCommand`で保持し、複数選択Objectも1回のUndoで復元する。

## 結果

診断で見つけた重複位置や面方向をローカル処理で修復できる。UVやカスタム法線はまだメッシュモデルに存在しないため、位置とトポロジーだけを対象とする。
