# ADR 0038: Knifeを境界Edge間のFace切断として実装する

## 決定

- 最初に選択した4頂点以上のFaceを対象とする。
- Faceの先頭Edgeと、頂点列上で反対側にあるEdgeへ同じ係数で切断点を置く。
- 切断点を共有する隣接Faceにも新Vertexを挿入し、T-junctionを作らない。
- 対象Faceの境界列を2経路へ分け、2つのFaceとその間の新Edgeを作る。
- 係数はダイアログ入力中にライブプレビューし、確定を1回のUndo単位にする。

## 結果

Quadとn-gonを直線で切断できる。現段階ではViewport上の任意点列をクリックする多段Knifeではなく、選択Face境界の2点を数値指定する決定的な操作である。
