# ADR 0008: 基本トポロジー操作の確定単位

## 状態

採用

## 決定

押し出し、分割、面生成、頂点結合、面反転は、編集対象メッシュの前後スナップショットを持つ単一のCommandとして確定する。複数オブジェクトへの操作はCompositeCommandへまとめる。

操作パラメーターはReactの一時状態に保持し、確定まではEditor Coreを変更しない。このためキャンセルは一時状態を破棄するだけで、モデル、選択、Undo履歴を操作前と同一に保てる。

トポロジー操作後はHalf-edge構造を再構築し、描画用頂点・面法線はメッシュrevisionの更新を契機に再生成する。再構築により操作対象メッシュ内の要素IDは更新されるため、確定後の要素選択は解除する。Undoでは操作前スナップショットと安定IDを完全に復元する。

## 理由

MVPでは局所差分による複雑なUndoより、検証可能で確実な復元を優先する。パラメーター編集中にモデルを変更しない方式はキャンセルを安全にし、ドラッグや数値変更ごとの履歴増加も防ぐ。

## 帰結

- 各確定操作の直後にメッシュ不変条件を検証する。
- Undo / Redoは同一スナップショットを復元する。
- 将来、要素IDを維持する局所トポロジー編集へ移行する場合もCommandの公開契約は変更しない。
