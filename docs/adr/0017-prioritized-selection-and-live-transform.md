# ADR 0017: 優先要素選択とリアルタイム移動

## 状態

採用

## 決定

モデル全体の選択はOutlinerのオブジェクト一覧に限定し、Viewportの選択モードには含めない。要素選択ではVertex / Edge / Faceを独立したフィルターとして複数同時に有効化できるようにする。クリック判定はVertex、Edge、Faceの順に実行し、最初にヒットした要素を返して後続判定を行わない。OutlinerでObjectを選択しても、要素フィルターの状態は維持する。

表示レイヤーはVertex / Edge / Faceをすべて初期表示とし、選択フィルターとは独立して切り替える。

種類が混在する選択集合を移動する場合は、各要素を構成する頂点IDの和集合へ変換する。共有頂点は一度だけ変換する。ギズモのドラッグ開始時に対象頂点と元のGPU位置をキャッシュし、`objectChange`ごとに位置・法線・境界球を更新してリアルタイムプレビューする。ドラッグ終了時にはプレビューを戻してEditor Coreへ移動量を1回だけ確定し、Undo履歴を1件に保つ。

## 理由

頂点上でEdgeやFaceが誤選択される曖昧さを優先順位で解消しながら、用途に応じて判定対象を絞り込める。ドラッグ中の形状追従と終了時の単一Commandを分離することで、操作の直接性と履歴の一貫性を両立する。
