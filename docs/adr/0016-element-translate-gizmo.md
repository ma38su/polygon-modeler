# ADR 0016: 編集要素の移動ギズモ

## 状態

採用

## 決定

Objectモードでは従来どおりオブジェクトへTransformControlsを接続する。Vertex / Edge / Faceモードで移動ツールが有効な場合は、選択要素を構成する一意な頂点集合のワールド座標中心へ専用ピボットを置き、TransformControlsを接続する。

ギズモ操作の終了時にワールド座標の移動量を各オブジェクトのローカル座標へ変換し、Editorの履歴付きメッシュ編集として確定する。Edgeは両端頂点、Faceと複数Faceは構成頂点を対象とし、共有頂点は一度だけ移動する。

新規Planeは上向き法線になる頂点順序で生成する。編集時の面は両面からRaycastできるようにし、視点が法線の裏側にある場合でもFace選択を可能にする。

## 理由

数値入力だけでは移動ツールを選んだ結果がViewportへ現れず、機能が未実装に見える。選択中心の共通ギズモを使うことで、Objectとメッシュ要素で一貫した直接操作を提供する。
