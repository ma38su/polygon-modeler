# ADR 0031: Face / Edgeの法線方向移動

## Status

Accepted

## Decision

- Face選択ではFace法線を、そのFaceの全頂点へ適用する。
- Edge選択では接続Faceの法線を平均し、Edge両端へ適用する。
- 複数要素が共有する頂点では寄与Faceを重複排除して平均する。
- 数値ダイアログの入力中は非破壊プレビューし、確定時に1コマンドとして記録する。

## Consequences

- 面・辺を現在の向きに沿って膨張・収縮できる。
- 非平面領域では頂点ごとの平均法線となり、各Faceを剛体として平行移動する操作ではない。
