# ADR 0010: プロジェクト形式と自動保存

## 状態

採用

## 決定

独自形式の拡張子は`.polyproj`、現在の`formatVersion`は1とする。外側はJSONとし、メタデータ、オブジェクト、Transform、可視性、Half-edgeトポロジー、安定IDを格納する。頂点座標はFloat64バイナリをBase64化して格納する。内部単位はメートルに固定する。

読込時はformatVersion、基本構造、バイナリ長、メッシュ不変条件を検証する。未対応バージョンと破損データは既存Documentを変更する前に拒否する。読込後はUndo / Redo履歴と選択を初期化し、新しい編集履歴を開始する。

未保存変更はEditor Coreが管理する。選択やモード変更ではDirtyにせず、モデル変更、Undo、RedoでDirtyにする。Dirtyな内容は500msのデバウンス後にIndexedDBへ自動保存し、次回起動時に復元候補として提示する。

## 理由

安定IDと完全なHalf-edge関係を保存することで、配列位置へ依存せず同じ編集モデルを復元できる。JSONの検査容易性を保ちつつ、座標列は将来のバイナリコンテナ化へ移行しやすい形にする。
