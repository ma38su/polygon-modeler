# ADR 0015: 選択モードから独立した表示レイヤー

## 状態

採用

## 決定

Object / Vertex / Edge / Faceの選択モードは、クリックや編集コマンドが対象とする要素種別だけを決定する。表示状態は別のVertex / Edge / Faceレイヤーとして管理し、それぞれを独立に表示・非表示にできるようにする。

Faceレイヤーを非表示にした場合も、Mesh自体は透明なピッキング対象としてSceneに残す。これにより外観と操作対象を分離し、Faceを隠した状態でも要素選択を継続できる。

VertexレイヤーはWebGPUとWebGLの両方で確実に面積を持つ小型の球体マーカーとしてインスタンス描画し、選択頂点はより大きなアクセント色のマーカーを重ねて強調する。`PointsMaterial`の点サイズはWebGPU経路で1px相当になる環境があるため使用しない。

## 理由

モデリング時に必要な補助表示は、現在の編集対象とは一致しない場合がある。たとえばFaceを選択しながら頂点と辺を同時に確認したり、面を隠して内部のワイヤーだけを確認したりするため、選択と表示を別状態として扱う。
