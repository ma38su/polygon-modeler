# ADR 0009: UI入力とフォーカスの契約

## 状態

採用

## 決定

グローバルショートカットは数値・文字入力を行うinput、textarea、select、contenteditable上ではフォーム本来の入力を優先する。ツールボタンの操作直後も選択や編集ショートカットは利用できる。Viewportはポインター操作時に自分へフォーカスを戻す。

現在の選択モード、ツール、選択数、頂点数、面数、描画バックエンド、未保存状態は常時表示する。Viewportのコンテキストメニューは全選択、選択解除、削除への補助経路とし、キーボード操作と同じEditor APIを呼ぶ。

ユーザー操作で回復可能なエラーは画面全体を停止せず通知として表示する。Reactツリー自体の例外はPhase 11のError Boundaryで分離する。

## 理由

数値入力中の削除やモード変更を防ぎつつ、Viewportへ戻ればショートカットを即座に利用できるようにするため。操作経路をEditor APIへ集約することで、マウスとキーボードの挙動差を抑える。
