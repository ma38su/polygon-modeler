# ADR 0023: Vertex / Edgeの基本ベベル

## Status

Accepted

## Decision

- 選択頂点から隣接頂点へ向かう各辺上に、指定率の切断点を作る。
- 元の面の角を2つの切断点へ置換し、閉じた頂点にはキャップ面を作る。
- Edge選択は、その辺の両端をベベル対象にする基本チャムファーとして扱う。
- インセット・押し出しと同じライブプレビュー可能な数値操作基盤を使う。

## Consequences

- VertexとEdgeの双方から、Undo可能な角落としを実行できる。
- 辺に沿った幅を一定に保つ高度なエッジループベベル、セグメント数、丸みは将来拡張とする。
