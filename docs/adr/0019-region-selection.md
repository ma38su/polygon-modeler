# ADR 0019: スクリーン領域による要素選択

## 決定

矩形選択と投げ縄選択はReact UIがポインター軌跡と選択領域のSVG表示を管理し、Viewportの`RegionPicker`が現在のCameraとObject Transformを使って要素をスクリーン座標へ投影する。Vertexは投影点、Edgeは中点、Faceは重心が領域内にある場合に選択する。Shiftドラッグでは既存選択へ追加する。

## 理由

入力表示、3D投影、Editor選択状態の責務を分離できる。領域判定はCPU実装として独立しているため、将来の交差判定改善やGPU pickingへの置換が容易になる。

## 帰結

領域選択中はOrbit操作とTransformギズモを無効化し、入力競合を避ける。現段階では要素中心基準の選択であり、辺・面との部分交差判定は将来拡張とする。
