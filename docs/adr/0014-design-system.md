# ADR 0014: デスクトップエディター向けデザインシステム

## 状態

採用

## 決定

色、文字、4px基準の余白、角丸、コントロール高さ、アイコン寸法、影、フォーカス、操作状態を`src/styles/design-system.css`のデザイントークンで管理する。

3Dモデラーは情報密度の高いデスクトップツールとして、本文12px、主要ブランド13px、補助表示11pxを基本とする。小型コントロールは高さ28px、通常コントロールは32px、ヘッダーは44pxに統一する。強調はサイズを過度に上げず、ウェイト、色、背景で表現する。

状態色は通常、hover、active、disabled、focus、danger、success、warningを共通化する。機能固有CSSはトークンを参照し、直接の寸法・色指定を増やさない。

## 理由

ヘッダー、Viewport、ツール、Inspectorで個別に指定されていた文字サイズ、余白、角丸を統一し、ウィンドウサイズが変わっても視覚的な階層と操作密度を維持するため。
