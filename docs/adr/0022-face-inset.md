# ADR 0022: 面インセットをプレビュー可能なトポロジー操作にする

## Status

Accepted

## Context

面の細分化を伴う操作では、確定前に結果を確認でき、キャンセル時に履歴とドキュメントを変更しないことが重要である。

## Decision

- 選択面ごとに中心へ補間した内周を作り、元の輪郭との間を四角面で接続する。
- 押し出しとインセットは共通の数値入力ダイアログを使う。
- 入力中は一時スナップショットだけをViewportへ渡し、確定時に1つのUndo可能なコマンドとして反映する。

## Consequences

- 単一面および離れた複数面を同じ操作でインセットできる。
- 隣接面をまとめて1つの領域として扱うリージョンインセットは、別のトポロジー実装として将来追加する。
