# Performance budgets

対象は100×100 Grid（10,000頂点、9,801四角面）で、CIでも再現できるVitestとして計測する。

| 操作                                                | 回帰上限 |
| --------------------------------------------------- | -------: |
| 構築・検証・Clone・Archive復元                      | 2,500 ms |
| 1頂点から全10,000頂点を連結選択                     | 1,000 ms |
| Face / Edge / Vertexを含む描画Geometry・Overlay準備 | 2,000 ms |
| 1頂点移動の確定とUndo                               | 1,000 ms |

閾値は共有CIの揺らぎを許容する回帰上限であり、目標フレーム時間ではない。ブラウザのGPU submitや描画完了時間はドライバー依存のため、このテストではCPU側のGeometry準備までを対象とする。
