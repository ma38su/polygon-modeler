# Polygon Modeler 操作ガイド

## 基本の流れ

1. 左の`Box追加`、`Plane追加`、`Cylinder追加`で形状を作成します。
2. 右側のオブジェクト一覧でモデル全体を選択します。Viewport上部左側のVertex / Edge / Faceは個別にON / OFFでき、同時に有効化できます。右側の表示レイヤーはVertex / Edge / Faceを個別に切り替えられ、初期状態ではすべて表示されます。Normalを有効にすると各Faceの向きを水色の線で確認できます。Inspectorのメッシュ診断には境界Edge、非manifold、退化Face、孤立Vertexの件数が表示されます。
   Object選択時のマテリアル欄では、色とBasic／Lambert（Gouraud系）／Phong／PBR Standardを選択できます。PBR Standardでは粗さと金属度を0〜1で設定でき、プロジェクト保存とGLB入出力にも保持されます。
   OutlinerではShift+クリックで複数Objectを選択できます。`複製`でコピーし、`結合`でTransformを頂点へ反映した単一メッシュへまとめます。`Mirror X / Y / Z`は元Objectを残し、ローカル座標の指定軸で反転したコピーを作ります。閉じた立体を2つ選択すると`Union`（和）／`Subtract`（先に並ぶObjectから後のObjectを差し引く）／`Intersect`（積）のBoolean演算を実行できます。
3. クリックまたは`⌘/Ctrl+A`で要素を選択します。Shift+クリックは追加・解除、`Alt+A`は全解除です。
   左の`矩形選択`または`投げ縄選択`ではドラッグ領域内の要素をまとめて選択でき、Shift+ドラッグで既存選択へ追加できます。
   Inspectorの`拡張`・`縮小`・`連結`でトポロジー上の隣接要素へ選択を展開できます。Edgeの`ループ`は頂点を通る連続線、`リング`は四角面の向かい側Edgeをたどります。Poleや分岐では曖昧な方向を選ばず停止します。
4. 左側はクリック・矩形・投げ縄の選択操作です。対象を選択した後、右側Inspector上部の`移動`・`回転`・`拡大縮小`を独立してONにするか、Inspectorの数値入力で編集します。数値入力は入力中に結果をライブ表示し、`適用`で1回の履歴として確定します。ギズモは選択頂点の重心に表示され、`World / Local / Normal`で軸を切り替えられます。LocalはObject軸、Normalは選択要素に隣接する面の平均法線をZ軸に使います。ギズモ操作中にShiftを押すと、移動0.05（Grid有効時は設定幅の1/10）、回転1度、スケール0.01の細かな刻みに切り替わります。
5. Faceでは押し出し・インセット・分割・面反転・面分離・法線移動、Edgeではベベル・分割・ループカット・法線移動、Vertexではベベル・面生成・頂点結合を利用できます。法線移動はFace法線またはEdgeの接続Face平均法線に沿って移動します。ループカットは選択Edgeから四角面の反対Edgeをたどり、指定位置に新しいEdge Loopを作ります。数値操作を選ぶとダイアログが開き、値の変更がViewportへライブ表示されます。確定ボタンで反映し、`キャンセル`で元の形状へ戻します。基本ベベルでは、Vertexはその角、Edgeは辺の両端の角を落とします。
   `押し出し操作`と`法線移動操作`は選択中心から平均法線方向へ専用ハンドルを表示します。法線軸をドラッグすると形状がライブ更新され、離した時点で1回の履歴として確定します。`押し出し数値`と`法線移動数値`では従来どおり正確な値をダイアログで指定できます。
   Loop Cut後は新しいEdge Loop、Extrude後は新しい先端Faceと境界Edge、Bevel後は新しいFaceとEdgeが自動選択されます。このため、カット後に対象Faceを選ぶだけでExtrudeからBevelへ選択を作り直さず続けられます。
   `Knife`は選択した4頂点以上のFaceについて、向かい合う境界Edge上の指定位置を結ぶ新しいEdgeで2面に切断します。切断点は隣接Faceにも挿入されるため、共有Edgeの接続を維持します。
   Object選択時のメッシュ診断から、指定距離以内の頂点を`Merge by Distance`で溶接できます。`法線再計算`は隣接Faceの向きを揃え、閉じた立体を外向きに修正します。どちらもUndoできます。
6. オブジェクト一覧またはVertex / Edge / Faceで対象を選択して右側の`移動`を有効にすると、選択中心に表示されるギズモで移動できます。ドラッグ中も形状が追従し、複数の面や異なる種類の要素もまとめて移動できます。操作はUndo / Redoの対象になります。
   Viewport上部の`Grid`で0.5単位のグリッドスナップ、`Vertex`・`Edge`・`Face`で未選択要素への吸着を個別に有効化できます。Vertexは頂点、Edgeは辺の中点、Faceは面の中心を対象とし、画面上12px以内で吸着します。X / Y / Zボタンまたは同名キーで操作軸を制限できます。
7. `保存`で`.polyproj`を保存し、`開く`で再編集します。
8. `GLB出力`または`STL出力`で交換ファイルを作成します。

## Viewport

- 左ドラッグ: オービット
- 右ドラッグ: パン
- ホイール: ズーム
- 透視 / 正投影: 投影方式の切り替え
- 右クリック: 選択・削除のコンテキストメニュー

Boxなどのモデル全体は右側のオブジェクト一覧から選択します。3Dモデル上ではVertex / Edge / Faceを自由に組み合わせられ、クリック位置をVertex、Edge、Faceの順に判定して最初に見つかった1要素だけを選択します。Shift+クリックで種類をまたいだ追加・解除ができます。選択要素は緑色で強調されます。

## 履歴と保存

`⌘/Ctrl+Z`でUndo、`⌘/Ctrl+Shift+Z`でRedoします。タイトル横の点は未保存変更を示します。未保存内容はIndexedDBへ自動保存され、次回起動時に復元候補が表示されます。

## 単位

内部単位とGLBはメートルです。STLは3Dプリント向けにミリメートルで入出力します。既定では非表示オブジェクトを出力しません。必要な場合は`非表示も出力`を有効にします。

## ショートカット

画面上部の`ショートカット`または`?`で一覧を表示できます。数値入力にフォーカスがある間は編集ショートカットを処理しません。
