# Polygon Modeler 操作ガイド

## 基本の流れ

1. 左の`Box追加`、`Plane追加`、`Cylinder追加`で形状を作成します。
2. Viewport上部左側のObjectまたはVertex / Edge / Faceで選択範囲を指定します。Vertex / Edge / Faceは個別にON / OFFでき、同時に有効化できます。右側の表示レイヤーも3種類を個別に切り替えられ、初期状態ではすべて表示されます。
3. クリックまたは`⌘/Ctrl+A`で要素を選択します。Shift+クリックは追加・解除、`Alt+A`は全解除です。
4. 左の移動・回転・拡大縮小、またはInspectorの数値入力で編集します。
5. Faceでは押し出し・分割・面反転、Edgeでは分割、Vertexでは面生成・頂点結合を利用できます。
6. ObjectまたはVertex / Edge / Faceを選択して左の`移動`を有効にすると、選択中心に表示されるギズモで移動できます。ドラッグ中も形状が追従し、複数の面や異なる種類の要素もまとめて移動できます。操作はUndo / Redoの対象になります。
7. `保存`で`.polyproj`を保存し、`開く`で再編集します。
8. `GLB出力`または`STL出力`で交換ファイルを作成します。

## Viewport

- 左ドラッグ: オービット
- 右ドラッグ: パン
- ホイール: ズーム
- 透視 / 正投影: 投影方式の切り替え
- 右クリック: 選択・削除のコンテキストメニュー

ObjectはBoxなどのメッシュ全体を選択するモードです。要素選択ではVertex / Edge / Faceを自由に組み合わせられ、クリック位置をVertex、Edge、Faceの順に判定して最初に見つかった1要素だけを選択します。Shift+クリックで種類をまたいだ追加・解除ができます。選択要素は緑色で強調されます。

## 履歴と保存

`⌘/Ctrl+Z`でUndo、`⌘/Ctrl+Shift+Z`でRedoします。タイトル横の点は未保存変更を示します。未保存内容はIndexedDBへ自動保存され、次回起動時に復元候補が表示されます。

## 単位

内部単位とGLBはメートルです。STLは3Dプリント向けにミリメートルで入出力します。既定では非表示オブジェクトを出力しません。必要な場合は`非表示も出力`を有効にします。

## ショートカット

画面上部の`ショートカット`または`?`で一覧を表示できます。数値入力にフォーカスがある間は編集ショートカットを処理しません。
